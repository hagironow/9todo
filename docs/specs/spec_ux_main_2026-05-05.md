## 1. 한 줄 요약

9칸 슬롯 격자를 중심으로, 드래그앤드랍 배치 → 완료/미루기/또하기 인터랙션을 게임 쾌감으로 설계한 메인 화면 UX 상세 사양.

## 2. 배경

### 페르소나의 좌절

- **지호**: "아침에 '오늘 뭐 하지?'로 시작해서 30분 낭비. 할 일이 20개인데 실제로 끝내는 건 2개." (personas.md)
- **수민**: "퇴근 후 '뭐부터 하지?' 고민하다 넷플릭스 시청. 매일 반복하는 배포 루틴을 매번 새로 적음." (personas.md)

### 이 사양이 다루는 범위

spec_mvp_2026-05-05.md가 데이터 모델, API, 컴포넌트 트리, 기본 UX 흐름을 정의했다면, 이 사양은 **인터랙션 세부 동작, 애니메이션, 상태별 시각 변화, Goal Compass MVP 포함, 드래그앤드랍 구체 사양**을 추가로 정의한다.

### 이번 확정 사항 (PO 방향 확정)

1. Goal Compass — MVP 포함 (경량: "나는" 인풋 + 목표 계층 + 확언만. 명언/프리셋 없음)
2. 드래그앤드랍 — 백로그 → 슬롯 배치가 핵심 인터랙션 (모달 방식은 보조 수단)
3. 미루기 = 백로그로 보냄 (슬롯 비워짐, 미룬 횟수 누적)
4. 또하기 = 항목 복사하여 새 슬롯에 재배정 가능 (복사본이 백로그에 생성)
5. 현재 시간대 행 활성, 나머지 dimmed

### 매칭 시나리오

scenarios.md 시나리오 A~H 전체 (MVP 포함 H: Goal Compass 방향 확인)

## 4. Goal Compass (MVP 경량 버전)

### 4-1. 구성 요소

Goal Compass는 시간표 위, 메인 영역 최상단에 위치한다. 세 가지 요소만 포함한다.

| 요소 | 내용 | 편집 방식 |
|---|---|---|
| "나는" 인풋 | "나는 [_________]이다" 형태 한 문장 | 인라인 편집 (클릭 → 포커스) |
| 목표 계층 | 10년/5년/1년/분기/오늘 — 각 한 줄 | 클릭 → 인라인 편집 |
| 확언 | 사용자가 직접 쓴 한 문장 | 클릭 → 인라인 편집 |

포함하지 않는 것: 명언 프리셋, 랜덤 로테이션, 외부 동기부여 콘텐츠 (non-goals.md 준수)

### 4-2. 접힘/펼침 동작

```
[기본 상태: 접힘]
┌── Goal Compass ▸ ─────────────────────────────────┐
│  "출시하지 않으면 아무것도 아니다"  (확언 한 줄 미리보기) │
└───────────────────────────────────────────────────┘

[펼쳐진 상태]
┌── Goal Compass ▾ ─────────────────────────────────┐
│  나는 [만드는 사람]이다                           │
│                                                   │
│  10년  최고의 프로덕트를 만드는 사람               │
│  5년   자체 SaaS 3개 운영                         │
│  1년   9todo MAU 1만 달성                      │
│  분기  MVP 출시 + 100명 온보딩                    │
│  오늘  9todo 시간표 UI 완성                    │
│                                                   │
│  확언: "출시하지 않으면 아무것도 아니다"           │
└───────────────────────────────────────────────────┘
```

- 헤더 행 클릭(또는 ▸/▾ 화살표 클릭) → 슬라이드 토글 (`max-height` CSS 트랜지션, 250ms ease-out)
- 접힌 상태에서 확언 미리보기를 항상 보여줘 맥락을 유지한다
- 최초 진입 시: 확언이 비어 있으면 펼침 상태로 시작 → "확언을 작성해 보세요" placeholder 표시

### 4-3. 인라인 편집

- 모든 텍스트 필드: 클릭 → `contenteditable` 또는 `<input>` 활성화 → 포커스 외 클릭 시 자동 저장
- 저장 시 로컬 JSON에 즉시 반영 (debounce 없이 blur 시 저장)
- 빈 상태 placeholder:
  - "나는": "만드는 사람, 1인 창업자, ..."
  - 목표 계층 각 행: "목표를 입력하세요"
  - 확언: "나만의 한 문장을 써보세요"

### 4-4. 데이터 모델 추가

```typescript
interface GoalCompass {
  identity: string;           // "나는 ___이다" 인풋
  goals: {
    tenYear: string;
    fiveYear: string;
    oneYear: string;
    quarter: string;          // 현재 분기 목표
    today: string;            // 오늘 핵심 1개
  };
  affirmation: string;        // 확언
}
```

`AppState`에 `goalCompass: GoalCompass` 필드 추가.

## 5. Now Focus

### 5-1. 표시 로직

```
현재 시각 → 현재 시간대(TimePeriod) 결정
  ↓
현재 시간대의 priority=1 슬롯 항목 → Now Focus
  ↓ (비어 있으면)
priority=2 → priority=3 순서로 폴백
  ↓ (전체 비어 있으면)
"지금 시간표가 비어 있어요" 빈 상태
```

### 5-2. 시각 디자인

```
┌───────────────────────────────────────────────────────┐
│  저녁 · 1순위                                [● 플로디] │
│                                                        │
│  사이드바 리팩터링                                     │
│                                                        │
│  [✓ 완료]   [→ 미루기]   [↻ 또하기]                  │
└───────────────────────────────────────────────────────┘
```

- 배경: `var(--accent)` (코랄 계열)
- 시간대·순위 레이블: 14px, 반투명 (`opacity: 0.7`)
- 컬러 도트: 우상단 고정
- 항목 제목: 24px bold, 최대 2줄 (2줄 초과 시 ellipsis)
- 루틴 인스턴스이면: 제목 옆 ↻ 아이콘 (회색, 14px)

### 5-3. 상태별 변화

| 상태 | 표시 |
|---|---|
| 정상 (항목 있음) | 위 디자인 그대로 |
| 빈 상태 (슬롯 없음) | "지금 시간표가 비어 있어요" + "백로그에서 드래그해 채워보세요" 힌트 |
| 완료 직후 (전환 중) | 2순위 항목이 슬라이드-업 애니메이션으로 올라옴 (300ms) |
| 모두 완료 (시간대 전체) | "이 시간대는 모두 완료했어요!" + 파티클 이펙트 |

## 6. 시간표 그리드 (3×3)

### 6-1. 시간대 행 상태

| 상태 | 시각 처리 |
|---|---|
| 현재 시간대 (활성) | `border-l-4` `var(--accent)` 보더 + `var(--card)` 배경 + 행 레이블 bold |
| 지나간 시간대 | `opacity: 0.45` (전체 행 dimmed) |
| 아직 오지 않은 시간대 | `opacity: 0.85` (약간 muted) |

현재 시간대는 `useCurrentPeriod` 훅이 60초마다 계산하여 실시간 갱신.

### 6-2. 슬롯 카드 — 채워진 상태

```
┌─────────────────────────────┐
│ ● [제목 텍스트]             │
│                             │
│              [②] ↻         │  ← deferCount 뱃지 + 루틴 아이콘
└─────────────────────────────┘
```

| 요소 | 스펙 |
|---|---|
| 컬러 도트 | 좌상단, 직경 8px, `var(--project-color)` |
| 제목 | 15px, 최대 2줄 ellipsis |
| deferCount 뱃지 | 우하단, 숫자만 표시 (0이면 숨김) |
| 루틴 아이콘 ↻ | 우하단, 루틴 인스턴스일 때만 표시 |
| 루틴 카드 테두리 | 점선 (`border-dashed`), `var(--muted)` 배경 |

**deferCount 단계별 시각화:**

| 횟수 | 뱃지 색상 | 카드 테두리 | 툴팁 |
|---|---|---|---|
| 0 | 없음 | 없음 | 없음 |
| 1 | `var(--muted-foreground)` 회색 | 없음 | 없음 |
| 2 | `var(--warning)` 주황 | 없음 | "2번 미뤘어요" |
| 3+ | `var(--destructive)` 빨강 | 주황 1px solid | "3번 미뤘어요. 진짜 할 건가요?" |

### 6-3. 슬롯 카드 — 상태별 시각 변화

**기본 (default):**
- 배경 `var(--card)`, 그림자 `var(--shadow-sm)`

**hover:**
- 그림자 `var(--shadow-md)` 강조
- 카드 우측에 액션 버튼 오버레이 페이드-인 (150ms)
  ```
  [✓ 완료]  [→ 미루기]  [↻ 또하기]
  ```

**dragging (드래그 중):**
- 원본 위치: `opacity: 0.35` + 점선 테두리 (유령 자리 표시)
- 드래그 핸들: `cursor: grabbing`, 카드 복사본이 마우스를 따라다님 (drop shadow 강조)

**완료 (completed):**
- 제목 `line-through` + `opacity: 0.5` 즉시 적용
- 이후 `animate-fade-out` 2초 후 DOM 제거

**미루기 직후 (deferred):**
- 슬롯에서 백로그 방향으로 슬라이드-아웃 모션 (300ms)
- 슬롯이 빈 상태로 전환

### 6-4. 슬롯 — 빈 상태

```
┌ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─┐
│           +              │  ← 점선 테두리, 중앙 + 아이콘
└ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─ ─┘
```

- 기본: 점선 테두리 (`border-dashed`), 배경 투명, + 아이콘 `var(--muted-foreground)`
- **드래그 오버 중**: 배경 `var(--accent-muted)` (연한 강조색), 테두리 `var(--accent)` solid, `scale(1.02)` 확대 (드랍 가능 신호)
- **클릭**: BacklogPickerModal 열림 (드래그앤드랍 보조 수단)
- **드래그 불가 슬롯** (이미 찬 슬롯 위에 다른 항목 드래그 시): `cursor: not-allowed`, 배경 `var(--destructive-muted)` 붉은 힌트

## 7. 핵심 인터랙션 상세

### 7-1. 드래그앤드랍 — 백로그 → 슬롯

드래그앤드랍은 이 앱의 **가장 핵심적인 인터랙션**이다. 스케줄링의 기본 방법.

**드래그 시작 (dragstart):**
1. 백로그 항목 또는 슬롯 카드를 길게 누르거나 드래그 시작
2. 드래그 핸들 커서 (`cursor: grab` → `cursor: grabbing`)
3. 드래그되는 카드: 반투명 드래그 프리뷰 생성 (원본 카드 모양, `opacity: 0.9`, `box-shadow` 강조)
4. 원본 위치: `opacity: 0.35` + 점선 테두리로 "유령 자리" 표시
5. 드랍 가능한 빈 슬롯 전체: 즉시 `var(--accent-muted)` 배경 + 흔들리는 펄스 애니메이션 시작 (드랍 가능 영역 시각화)

**드래그 중 (dragover):**
- 빈 슬롯 위: 해당 슬롯만 `scale(1.03)` + 테두리 `var(--accent)` solid로 강조 (착지 예고)
- 채워진 슬롯 위: `cursor: not-allowed`, 붉은 오버레이 (드랍 불가)
- 백로그 영역 위: 드랍 가능 (슬롯 → 백로그로 반환 시)

**드랍 (drop):**
1. 항목이 슬롯에 착지하는 "끼워 넣기" 애니메이션:
   - 카드가 슬롯 위치로 수렴하는 커브 모션 (200ms cubic-bezier)
   - 슬롯 카드 scale: 1.05 → 1.0 바운스 (150ms)
2. 상태 업데이트: `slot` 필드에 좌표 기록
3. 백로그에서 항목 제거
4. 드랍 가능 영역 강조 모두 해제
5. 전체 슬롯이 채워졌을 때 (9칸 꽉 참): 짧은 효과음 or 진동 피드백 (옵션)

**드랍 실패 (drop outside):**
- 드래그 프리뷰가 원본 위치로 되돌아오는 스냅-백 애니메이션 (200ms ease-in)
- 모든 강조 효과 해제

**터치 지원 (모바일):**
- 터치앤홀드 150ms → 드래그 시작 (진동 피드백 선택적)
- 손가락으로 슬롯 위를 지나가면 해당 슬롯 강조
- 손가락 뗌 → 드랍

**드래그앤드랍 대안: 빠른 배치 (모달):**
- 백로그 항목의 [슬롯 배치] 버튼 클릭 → SlotPickerModal (3×3 격자)
- 빈 슬롯의 [+] 클릭 → BacklogPickerModal
- 드래그앤드랍이 불편한 상황(소형 화면, 정밀도 필요)에서 보조 수단으로 사용

### 7-2. 완료 체크

**클릭 흐름:**
```
1. 카드 hover → [✓ 완료] 버튼 표시 (또는 Now Focus의 [✓] 버튼)
2. 클릭 시:
   a. 버튼 즉시 비활성화 (중복 클릭 방지)
   b. 체크 아이콘 애니메이션: 원이 그려지며 체크 표시 (SVG 드로우 애니메이션, 400ms)
   c. 카드 제목에 line-through 즉시 적용
   d. 카드 전체 opacity: 1.0 → 0.0 (fade-out, 600ms)
   e. 슬롯이 빈 상태로 전환 (점선 + 아이콘)
   f. Now Focus: 다음 순위 항목 슬라이드-업 (300ms)
3. completedAt = 현재 시각 기록
```

**게임 쾌감 연출:**
- 체크 완료 시 파티클 효과: 작은 색상 점들이 카드에서 사방으로 퍼지는 burst (0.5초)
- 파티클 색상: 해당 프로젝트의 컬러 도트 색상 기반
- 소리: 없음 (MVP에서는 시각 효과만)

**시간대 전체 완료 시:**
- 해당 시간대 행에 "다 깼다!" 토스트 메시지 (2초 후 사라짐)
- 행 배경이 연한 초록으로 0.5초 flash

**하루 전체 완료 시 (9칸 모두 체크):**
- 전체 화면 파티클 burst (1.5초)
- "오늘 하루를 모두 깼어요!" 모달 또는 배너 (닫기 버튼 있음)

### 7-3. 미루기

**버튼 위치:**
- Now Focus: 제목 아래 우측 [→ 미루기] 버튼
- 슬롯 카드 hover 시: 액션 오버레이에 [→ 미루기]
- 모바일: 카드 좌에서 우 스와이프 → 미루기 트리거 (스와이프 행동 힌트는 첫 사용 시 가이드)

**클릭 후 애니메이션:**
```
1. 카드가 화면 하단(백로그 방향)으로 슬라이드-아웃 (300ms, ease-in)
2. 슬롯이 빈 상태로 전환
3. 백로그가 접혀 있으면 잠깐 열렸다 닫히며 항목이 추가됨을 암시 (백로그 헤더 숫자 +1 강조)
4. deferCount 뱃지: 카드에 표시 (백로그에서도 동일하게 표시)
```

**자각 유도:**
- deferCount === 3 시점에 짧은 알림 텍스트 표시: "3번 미뤘어요. 오늘 할 수 있을까요?" (카드 아래에 3초 표시 후 사라짐)
- 이 텍스트는 사용자를 비난하지 않고 자각을 유도하는 톤으로 작성

### 7-4. 또하기 (Replay)

**버튼 위치:**
- Now Focus: [↻ 또하기] 버튼
- 슬롯 카드 hover 시: 액션 오버레이에 [↻ 또하기]
- 모바일: 카드 우에서 좌 스와이프 → 또하기 트리거

**클릭 후 흐름:**
```
1. 클릭 시:
   a. 원본 카드에 "복사됨" 토스트 오버레이 (1초, fade 후 사라짐)
   b. 원본 카드는 그 자리에 유지 (원본은 변하지 않음)
   c. 복사본이 백로그에 생성 (백로그 헤더 숫자 +1 강조)
   d. 백로그가 접혀 있으면 잠깐 열렸다 닫히며 복사본 추가를 암시

2. 사용자가 직접:
   - 백로그에서 복사본을 드래그앤드랍으로 원하는 슬롯에 배치
   - 또는 복사본의 [슬롯 배치] 버튼 클릭 → SlotPickerModal

3. 복사본 식별:
   - 백로그에서 "(복사)" 접미사 없이 동일 제목으로 표시
   - 단, deferCount는 0으로 초기화 (새 항목처럼 시작)
```

**또하기 vs 미루기 차이:**
- 미루기: 원본이 백로그로 이동 (슬롯 비워짐)
- 또하기: 원본은 그대로, 복사본이 백로그에 추가 (슬롯 유지됨)

### 7-5. 빠른 추가 (QuickInput)

**위치 및 구조:**
```
[데스크톱] 메인 영역 최상단 (Goal Compass 아래, Now Focus 위)
[모바일] 하단 고정 플로팅 버튼 [+] → 인풋 열림

┌──────────────────────────────────────────────────┐
│  ● [할 일 추가... (@프로젝트명으로 연결)] [반복↺] [추가] │
└──────────────────────────────────────────────────┘
   ↑ 컬러 도트    ↑ 텍스트 인풋                  ↑ 토글
   (클릭 → ProjectPicker)              (활성화 시 루틴 모드)
```

**추가 후 피드백:**
1. 인풋 텍스트 클리어 + 포커스 유지
2. 백로그 헤더 숫자 +1 애니메이션 (숫자가 튀어오르는 bounce, 300ms)
3. 백로그가 접혀 있으면 헤더가 살짝 강조 (0.5초 flash)
4. 추가된 항목이 백로그에 스무스하게 삽입 (slide-in, 200ms)

**모바일 빠른 추가:**
- 하단 플로팅 [+] 버튼 (우하단 고정)
- 클릭 시 하단 시트(Bottom Sheet)로 인풋 열림
- 완료 후 시트 닫힘

## 8. 슬롯 카드 액션 접근 방법 — 플랫폼별

### 8-1. 데스크톱

- **hover 시 액션 오버레이**: 카드 우측에 버튼 3개 페이드-인
  ```
  [✓]  [→]  [↻]
  완료  미루기  또하기
  ```
- 버튼 크기: 28×28px, 아이콘만 (레이블 없음 — 툴팁으로 보완)
- 카드가 너무 작으면 (좁은 레이아웃): 마우스 오른쪽 클릭 → 컨텍스트 메뉴로 대체

### 8-2. 모바일

- **스와이프 제스처:**
  - 좌 → 우 스와이프: 미루기 (주황 배경 + 화살표 아이콘 드러남)
  - 우 → 좌 스와이프: 또하기 (파란 배경 + ↻ 아이콘 드러남)
  - 스와이프 임계값: 카드 너비의 30% 이상
- **탭 → 카드 상세/편집**: 탭 시 하단 시트(Bottom Sheet) 열림
  ```
  ┌──────────────────────────┐
  │  ● [제목]                │
  │                          │
  │  [✓ 완료]                │
  │  [→ 미루기]              │
  │  [↻ 또하기]              │
  │  [✏ 제목 수정]           │
  │  [🗑 삭제]               │
  └──────────────────────────┘
  ```
- 첫 사용 시 스와이프 가이드 툴팁 1회 표시 후 localStorage에 `swipe-hint-seen: true` 저장

## 9. 백로그 패널

### 9-1. 구조

```
▾ 백로그 (5개 항목)
├── ● 플로디 (3)
│   ├── ○ 사이드바 리팩터링    [슬롯 배치] ②
│   ├── ○ 버그 수정            [슬롯 배치]
│   └── ○ PR 작성             [슬롯 배치]
│
└── ● 블로그 (2)
    ├── ○ 포스트 초안           [슬롯 배치]
    └── ↻ 쓰레드 배포 (루틴)    [슬롯 배치]
```

- 항목 행: 드래그 핸들 (`⠿`) + 컬러 도트 + 제목 + deferCount 뱃지 + [슬롯 배치] 버튼
- 루틴 인스턴스: ↻ 아이콘 + 점선 테두리 (시간표 카드와 일관)
- "미분류" 그룹: 프로젝트 없는 항목 (컬러 도트 없음, 회색 도트)

### 9-2. 드래그 소스

백로그 항목은 드래그앤드랍의 시작점이다.
- 드래그 핸들(`⠿`) 또는 항목 전체 영역에서 드래그 시작 가능
- 드래그 중에는 백로그 내 순서 변경 불가 (슬롯 배치용 드래그만 지원)

### 9-3. 빈 상태

```
▾ 백로그 (0개 항목)

  여기는 아직 비어 있어요.
  상단 인풋으로 할 일을 추가해보세요.
```

## 11. 항목 생명주기 — 상태 전이도

```
[생성]
   │ QuickInput 입력 → Enter
   ↓
[백로그]  ←─────────────────────────────┐
   │                                    │
   │ 드래그앤드랍 또는 SlotPickerModal   │ 미루기
   ↓                                    │
[슬롯 배정 (scheduled)]                 │
   │                   │               │
   │ 완료 체크         │ 미루기 버튼    │
   ↓                   ↓               │
[완료]               [백로그] ──────────┘
(completedAt 기록)     ↑
                       │ 또하기 버튼
                   [복사본 생성 → 백로그]
                       │
                       │ 드래그앤드랍
                       ↓
                   [새 슬롯 배정]
```

### 전이별 트리거와 피드백

| 전이 | 트리거 | 피드백 |
|---|---|---|
| 생성 → 백로그 | QuickInput Enter | 백로그 숫자 bounce +1 |
| 백로그 → 슬롯 | 드래그앤드랍 또는 SlotPickerModal | 카드 착지 바운스 + 슬롯 강조 해제 |
| 슬롯 → 완료 | 체크 버튼 | 파티클 burst + fade-out + Now Focus 갱신 |
| 슬롯 → 백로그 (미루기) | 미루기 버튼 / 좌→우 스와이프 | 슬라이드-아웃 (슬롯 방향 → 하단) + deferCount +1 |
| 또하기 → 복사본 백로그 | 또하기 버튼 / 우→좌 스와이프 | "복사됨" 토스트 + 백로그 숫자 +1 |
| 루틴 완료 | 체크 버튼 | 파티클 burst + 다음 날 인스턴스 예약 (날짜 롤오버 시 생성) |

## 12. 게임 쾌감 요소 정리

| 요소 | 구현 방법 | 강도 |
|---|---|---|
| 슬롯 완료 파티클 | CSS/Canvas 작은 색상 점 burst, 0.5초 | 중 |
| 시간대 전체 완료 flash | 행 배경 초록 flash 0.5초 + 토스트 | 약 |
| 하루 전체 완료 | 전체 화면 파티클 + 배너 | 강 |
| 드래그 착지 바운스 | scale 1.05 → 1.0, 150ms | 약 |
| 백로그 숫자 bounce | 숫자 scale 1.3 → 1.0, 300ms | 약 |
| deferCount 색상 경고 | 회색 → 주황 → 빨강 단계적 에스컬레이션 | 중 |
| Now Focus 슬라이드-업 | 다음 항목이 아래서 위로 등장, 300ms | 약 |
| 체크 SVG 드로우 | 원+체크 그려지는 SVG 애니메이션, 400ms | 중 |

**파티클 구현 방침:**
- Canvas 2D 또는 CSS 애니메이션 (라이브러리 없이 직접 구현)
- 파티클 수: 12~18개 (너무 많으면 산만함)
- 지속 시간: 0.5초 (너무 길면 작업 흐름 방해)

## 13. 진행 상태 시각화

### 13-1. 슬롯 채움 현황

시간표 그리드 상단에 작은 진행 표시:

```
오늘 3 / 9  ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━  (완료 기준)
```

또는 각 시간대 행 레이블 옆에:

```
아침 ●●○  저녁 ●○○★  밤 ○○○
       ↑ 완료  ↑ 미배정    ↑ 현재 시간대
```

- `●` = 완료, `●` (흐리게) = 배정됨, `○` = 빈 슬롯
- 색상: 완료 = `var(--success)` 초록, 배정 = `var(--primary)`, 빈 = `var(--border)`

### 13-2. 모바일 진행 표시

현재 시간대 탭 레이블에 미니 진행 표시:

```
[아침 2/3]  [저녁★ 1/3]  [밤 0/3]
```

## 17. 검증 방법

아래 시나리오 흐름이 모두 동작하면 이 UX 사양 완료:

1. **Goal Compass**: 앱 최초 진입 시 Goal Compass 펼쳐짐 + placeholder 표시. 클릭하여 확언 작성 → blur 시 저장. 접힘 시 확언 미리보기 유지.

2. **드래그앤드랍 스케줄링**: 백로그 항목을 드래그 → 빈 슬롯 강조 → 착지 시 바운스 애니메이션 + 슬롯에 카드 표시. 채워진 슬롯 위: not-allowed 표시. 드래그 실패: 원위치 스냅백.

3. **완료 게임 쾌감**: 체크 클릭 → SVG 드로우 + 파티클 burst + fade-out → 슬롯 비워짐 → Now Focus 다음 항목 슬라이드-업. 시간대 전체 완료 시 flash + 토스트.

4. **미루기 모션**: 미루기 클릭 → 카드 슬라이드-아웃 (하단 방향) → 슬롯 비워짐 → 백로그 숫자 +1. deferCount 3 시점 경고 텍스트 표시.

5. **또하기 흐름**: 또하기 클릭 → 원본 카드 "복사됨" 토스트 → 원본 유지 → 백로그에 복사본 추가 → 복사본 드래그 → 새 슬롯 배치.

6. **모바일 스와이프**: 카드 좌→우 스와이프 → 주황 배경 드러남 → 임계값 통과 시 미루기 실행. 우→좌 스와이프 → 파란 배경 → 또하기 실행. 첫 사용 시 힌트 표시.

7. **시간대 하이라이트**: 현재 시간대 행 bold + 좌측 강조 보더. 지나간 행 dimmed. 60초마다 갱신.

## 18. 미해결 / 결정 필요

1. **또하기 워딩**: "또하기"는 임시 워딩 (core-concepts.md 명시). 더 나은 이름 추후 결정. 후보: "한 번 더", "이어하기", "복제", "Replay".

2. **드래그앤드랍 라이브러리 vs 직접 구현**: HTML5 DnD API 직접 사용 시 모바일 터치 지원이 별도 필요. `@dnd-kit/core` 사용 시 번들 +20KB이지만 터치+마우스 통합 지원. 결정 필요.

3. **파티클 완료 이펙트 구현 방법**: Canvas 2D 직접 구현(복잡) vs CSS 애니메이션(단순하지만 제한적) vs 경량 라이브러리(`canvas-confetti`, 3KB). 결정 필요.

4. **슬롯 → 슬롯 이동 (드래그)**: 채워진 슬롯에서 다른 빈 슬롯으로 드래그 이동 지원 여부. 현재 사양에서 제외했으나, 아침 세팅 시 순서 변경 니즈가 있을 수 있음. Phase 2로 확인.

5. **Goal Compass "오늘" 필드와 Now Focus 연동**: concept.md에 "연동 가능"으로 명시됐으나 구체 동작 미결정. 별도 필드로 독립 운영 vs Now Focus 1순위와 자동 연동. MVP에서는 독립 필드로 결정(사용자 직접 입력).

6. **스와이프 제스처 임계값**: 카드 너비의 30%로 제안됨. 실기기 테스트 후 조정 필요.
