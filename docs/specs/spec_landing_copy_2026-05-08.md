# Spec: 홈페이지 랜딩 카피 튜닝

> 작성일: 2026-05-08
> 작성: planner
> 상태: 검토 중
> 범위: 랜딩 페이지 카피 & 구성
> 페르소나: 지호 (1차 — 바이브 코더), 수민 (2차 — 사이드 프로젝트 메이커)

---

## 1. 한 줄 요약

기능이 확장된 현재 9todo의 가치를 정확히 전달하도록 랜딩 페이지 카피와 섹션 구성을 재설계한다.

---

## 2. 배경

### 현재 상태

- 별도 랜딩 페이지 없음 — `page.tsx`가 곧바로 앱 대시보드
- MVP 이후 기능이 크게 확장됨:
  - **뽀모도로 타이머** — NowFocus에 15~60분 집중 타이머 내장
  - **노트** — 슬롯별 스티키 노트 (메모·회고 기록)
  - **프로젝트별 상세 뷰** — 프로젝트 단위 태스크/루틴/노트 통합 보기
  - **캘린더 뷰** — 주간/월간 시각화, 일별 XP 표시
  - **검색** — 전체 태스크·노트 풀텍스트 검색
  - **XP 시스템** — 완료 시 경험치 누적, 게이미피케이션 강화

### 카피 튜닝이 필요한 이유

1. 초기 카피는 "9칸 슬롯 + 드래그" 핵심만 전달 → 확장된 기능 누락
2. 뽀모도로·노트·프로젝트 뷰가 들어오면서 "단순 할일 앱"이 아닌 **집중 실행 도구**로 포지셔닝 확장 필요
3. 경쟁 앱 대비 차별점이 "슬롯 제한" 하나에서 "슬롯 → 집중 → 기록 → 회고"의 루프로 진화

### 매칭 시나리오

- scenarios.md 시나리오 A (아침 세팅), B (NowFocus 집중), H (Goal Compass 방향)
- 신규: 뽀모도로 집중 → 노트 기록 → 프로젝트별 회고 루프

---

## 3. 핵심 메시지 전략

### 3.1 포지셔닝 시프트

| AS-IS | TO-BE |
|-------|-------|
| "9칸에 오늘을 끼워넣는 게임" | "9칸에 오늘을 끼워넣고, 집중하고, 기록한다" |
| 시간 배분 앱 | 시간 배분 → 집중 실행 → 회고 루프 |
| 드래그가 핵심 인터랙션 | 드래그 → 타이머 → 노트가 하나의 흐름 |

### 3.2 밸류 체인 (유저 여정 순서)

```
① 배치 — 9칸에 오늘 할 일을 끼워넣는다
② 집중 — 뽀모도로 타이머로 지금 하나에 몰입한다
③ 기록 — 노트로 과정과 메모를 남긴다
④ 회고 — 프로젝트별로 쌓인 기록을 본다
⑤ 방향 — Goal Compass로 큰 그림을 확인한다
```

### 3.3 톤 & 보이스

- **짧고 직접적** — 지호는 읽지 않는다, 스캔한다
- **게임 메타포 유지** — "슬롯", "깨다", "XP" 용어 사용
- **한국어 기본** — 영어 키워드 자연스럽게 섞어도 OK
- **과장 금지** — "혁명적", "유일한" 같은 표현 배제

## 4. 랜딩 페이지 섹션 구성

### 4.1 Hero 섹션

**목적:** 3초 안에 "이게 뭔지" 전달

| 요소 | 내용 |
|------|------|
| 헤드라인 (1안) | "오늘 하루, 딱 9칸." |
| 헤드라인 (2안) | "9칸에 끼우고, 집중하고, 기록한다." |
| 헤드라인 (3안) | "할 일은 많고 시간은 없을 때, 9칸이면 충분하다." |
| 서브카피 | "하루를 아침·오후·저녁 × 3개 우선순위로 나누고, 타이머로 집중하고, 노트로 기록하는 시간 배분 앱." |
| CTA | "지금 시작하기" (로그인/앱 진입) |
| 비주얼 | 3×3 그리드에 태스크가 드래그되는 애니메이션 or 스크린샷 |

### 4.2 핵심 가치 섹션 — "이렇게 작동합니다"

4개 스텝을 비주얼 카드로:

**Step 1: 배치**
- 아이콘: 그리드
- 카피: "9칸 슬롯에 오늘 할 일을 드래그해서 넣으세요."
- 서브: "아침·오후·저녁 × 우선순위 3단계. 최대 9개만."

**Step 2: 집중**
- 아이콘: 타이머
- 카피: "뽀모도로 타이머로 지금 하나에 몰입하세요."
- 서브: "15분~60분, 원하는 만큼. Now Focus가 지금 할 일을 보여줍니다."

**Step 3: 기록**
- 아이콘: 노트
- 카피: "떠오르는 생각, 바로 노트에 적으세요."
- 서브: "슬롯마다 노트가 붙습니다. 작업 중 메모, 회고, 아이디어."

**Step 4: 회고**
- 아이콘: 차트/프로젝트
- 카피: "프로젝트별로 쌓인 기록을 한눈에 보세요."
- 서브: "태스크, 루틴, 노트를 프로젝트 단위로 모아봅니다."

### 4.3 기능 하이라이트 섹션

각 기능을 스크린샷/GIF + 짧은 카피로:

| 기능 | 카피 | 상세 |
|------|------|------|
| **9칸 슬롯** | "하루의 용량은 9칸이다" | 3×3 그리드. 드래그앤드랍으로 배치. 슬롯이 제한이자 전략. |
| **Now Focus** | "지금 이 순간, 이것만" | 현재 시간대 1순위 자동 표시. 결정 피로 제로. |
| **뽀모도로 타이머** | "타이머 누르고, 몰입" | 15~60분 설정. 완료 시 자동 체크 + XP 획득. |
| **노트** | "생각이 날 때, 바로 적는다" | 슬롯에 붙는 스티키 노트. 작업 중 메모·회고·아이디어. |
| **프로젝트 뷰** | "프로젝트별로 모아본다" | 태스크·루틴·노트를 프로젝트 단위로 통합 조회. |
| **Goal Compass** | "오늘의 슬롯이 큰 그림과 연결된다" | 오늘~5년 목표 계층 + "나는 ___이다" 정체성 선언. |
| **미루기 & 또하기** | "못 끝내도 괜찮다" | 미루기 = 백로그로. 또하기 = 복사해서 재배치. 실패에 유연하게. |
| **캘린더** | "주간·월간으로 돌아보기" | 완료한 태스크를 날짜별로 시각화. |
| **XP 시스템** | "매일 쌓이는 경험치" | 완료할 때마다 XP 획득. 성장 기록이 보인다. |

### 4.4 페르소나별 공감 섹션 (선택)

**바이브 코더에게:**
> "사이드 프로젝트 3개 돌리면서 '오늘 뭐 하지?' 30분 고민하다 하루가 끝나본 적 있다면 — 9칸이면 충분합니다."

**사이드 프로젝트 메이커에게:**
> "퇴근 후 3시간. 뭐부터 할지 고민하다 넷플릭스 켠 적 있다면 — 저녁 슬롯 3개에 답이 있습니다."

### 4.5 CTA 섹션 (하단)

| 요소 | 내용 |
|------|------|
| 헤드라인 | "오늘 하루를 9칸으로 시작해보세요." |
| 서브카피 | "가입 없이 바로 시작. 데이터는 내 브라우저에 저장됩니다." |
| CTA 버튼 | "지금 시작하기" |
| 신뢰 요소 | "로컬 저장 · 무료 · 오픈소스" |

## 5. 카피 원칙

### DO
- 숫자 사용 ("9칸", "3초", "15분")
- 동사 시작 ("끼우고", "집중하고", "기록한다")
- 유저 행동 기반 ("드래그해서", "타이머 누르고", "노트에 적고")
- 제한이 가치임을 강조 ("9칸이면 충분하다", "최대 9개만")

### DON'T
- "혁신적인", "유일한", "최고의" 등 과장 수식어
- 기능 나열식 ("~도 되고 ~도 되고 ~도 됩니다")
- 경쟁 앱 비교 언급
- 영어 전용 카피 (한국어 기본, 영어 키워드는 자연스럽게)

## 6. 기술 구현 참고

### 현재 파일 구조

- 앱 진입점: `src/app/page.tsx` (현재 대시보드)
- 랜딩 페이지 신규 생성 필요: `src/app/landing/page.tsx` 또는 비로그인 시 `page.tsx` 분기

### 구현 방식 (제안)

1. **방식 A (분기):** `page.tsx`에서 첫 방문자/비로그인 → 랜딩 뷰, 기존 유저 → 대시보드
2. **방식 B (별도 라우트):** `/landing` 또는 `/` 를 랜딩으로, `/app`을 대시보드로 분리

### 필요 에셋

- 3×3 그리드 스크린샷 또는 애니메이션 GIF
- NowFocus + 타이머 스크린샷
- 노트 기능 스크린샷
- 프로젝트 상세 뷰 스크린샷
- 아이콘 세트 (그리드, 타이머, 노트, 차트)

## 8. 비포함 (Non-goals)

- Phase 2 기능 (Romi, TodoLeague, 태그) 카피에 포함하지 않음
- 영어 다국어 랜딩은 이번 범위 밖
- 가격 정책/결제 관련 카피 없음 (무료 앱)
- SEO 최적화는 별도 작업
