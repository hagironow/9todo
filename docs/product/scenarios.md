# Scenarios

## 1단계: 핵심 시나리오 (MVP 범위)

### 시나리오 A: 아침에 오늘의 시간표 세팅하기

1. 지호가 아침에 9todo을 연다.
2. 어제 완료되지 않은 항목이 있으면 백로그에 남아있다.
3. 백로그에서 오늘 할 항목을 **드래그 앤 드랍**으로 3x3 격자의 슬롯에 배치한다.
4. 새로운 할 일이 있으면 상단 인풋에 텍스트를 입력하고, 최근 사용 프로젝트가 자동 연결된다.
5. 백로그에 추가된 항목을 드래그해서 슬롯에 끼운다.
6. Now Focus에 아침 1순위가 자동 표시된다. "이것만 하면 된다."
7. 슬롯을 채워가는 과정 자체가 게임 시작 전 전략 세팅처럼 느껴진다.

### 시나리오 B: Now Focus로 집중하고 완료하기

1. 지호가 오후에 9todo을 연다.
2. Now Focus에 저녁 시간대 1순위가 표시되어 있다.
3. 해당 작업을 수행한다.
4. 완료 후 체크하면 취소선 + fade-out으로 사라진다. 슬롯을 깬 쾌감.
5. 2순위가 자동으로 Now Focus에 올라온다.

### 시나리오 C: 미루기 -- 백로그로 보내기

1. 지호가 아침 1순위 작업을 시작했지만 오늘은 도저히 못 하겠다.
2. "미루기" 버튼을 누른다.
3. 해당 항목이 **백로그로 이동**한다. 미룬 횟수가 1 표시된다.
4. 슬롯이 비워진다. 나중에 백로그에서 다시 배정할 수 있다.
5. 미룬 횟수가 쌓이면 "3번 미뤘네" 표시로 자각을 유도한다.

### 시나리오 D: 또하기 -- 슬롯에 재배정

1. 지호가 아침에 "블로그 글 작성"을 완료했는데, 한 번 더 비슷한 작업을 해야 한다.
2. 또는 못 끝냈지만 다른 시간대에 이어서 하고 싶다.
3. "또하기" 버튼을 누른다.
4. 해당 항목이 복사되어 백로그에 나타난다.
5. 드래그 앤 드랍으로 원하는 슬롯(예: 저녁 2순위)에 재배정한다.

### 시나리오 E: 루틴 등록과 자동 재생성

1. 지호가 매일 저녁에 "쓰레드 배포"를 해야 한다.
2. 새 루틴을 생성하고 반복 주기를 "매일"로 설정한다.
3. 시간대(저녁)와 우선순위(2순위)를 지정한다.
4. 매일 해당 슬롯에 루틴이 자동 배치된다. 점선 테두리와 반복 아이콘으로 구분된다.
5. 완료하면 다음 날에 자동 재생성된다.

### 시나리오 F: 백로그에서 스케줄링

1. 지호가 "플로디 사이드바 리팩터링"이라는 생각이 떠올랐다.
2. 상단 인풋에 빠르게 입력한다. 프로젝트 "플로디"가 자동 연결된다.
3. 지금 당장 할 일은 아니므로 백로그에 남겨둔다.
4. 나중에 여유가 생기면 백로그를 펼쳐서 프로젝트별로 그룹핑된 항목을 확인한다.
5. 원하는 항목을 드래그 앤 드랍으로 빈 슬롯에 배치한다.

### 시나리오 G: 프로젝트별 필터링

1. 지호가 "플로디" 프로젝트에 집중하고 싶다.
2. 사이드바의 프로젝트 목록에서 "플로디"의 컬러 도트를 클릭한다.
3. 시간표와 백로그가 플로디 관련 항목만 필터링되어 표시된다.
4. 해당 프로젝트의 남은 작업 현황을 한눈에 파악한다.

### 시나리오 H: Goal Compass로 방향 확인

1. 지호가 아침에 9todo을 열면, 시간표 위에 Goal Compass가 보인다.
2. 본인이 직접 작성한 확언이 표시된다: "출시하지 않으면 아무것도 아니다"
3. 오늘의 작업이 이 확언과 맞닿아 있음을 확인하고 시간표 세팅에 들어간다.
4. 확언을 수정하고 싶으면 직접 편집한다.

### 시나리오 I: 로미와 함께 아침 세팅하기

1. 지호가 아침에 9todo을 처음 연다.
2. 우측 하단에서 로미가 등장한다: "안녕하세요! 저는 우선순위 도우미 로미에요. 오늘은 어떤 일을 완료해볼까요?"
3. 지호가 "투두슬롯 MVP 완성"을 입력한다.
4. 로미: "좋아요! 이걸 끝내려면 어떤 작업들이 필요할까요? 하나씩 적어보세요."
5. 지호가 하위 태스크를 적는다: "드래그앤드랍 구현", "파티클 이펙트", "배포"
6. 로미: "3개면 오전 슬롯에 딱 맞겠네요! 배치해볼까요?"
7. 태스크들이 자동으로 오전 1~3순위 슬롯에 배치된다.
8. 남은 슬롯(6칸)에 대해 다른 프로젝트 작업을 추가할지 묻는다.

### 시나리오 J: 태그로 작업 종류별 모아보기

1. 지호가 "플로디" 프로젝트에 여러 태스크를 추가했다.
2. 각 태스크에 태그를 붙인다: "사이드바 리팩터링" → #개발, "랜딩 페이지" → #기획, "SNS 배포" → #배포
3. 사이드바에서 #개발 태그를 클릭하면 개발 관련 태스크만 필터링된다.
4. 프로젝트와 무관하게, 오늘 "개발" 성격의 작업이 몇 개인지 한눈에 보인다.

## 2단계: 확장 시나리오

### 시나리오 K: macOS 위젯으로 지금 할 것 확인

1. 지호가 코딩 중 "지금 뭘 해야 하지?" 싶을 때 macOS 위젯을 본다.
2. Small 위젯에 현재 시간대 1순위가 표시되어 있다.
3. 탭하면 9todo 웹앱으로 이동한다.

### 시나리오 J: 모바일에서 빠른 확인

1. 지호가 외출 중 폰으로 9todo을 연다.
2. 아침/저녁/밤 탭으로 전환하며 현재 시간대의 할 일 3개를 확인한다.
3. 완료 체크 또는 미루기를 빠르게 처리한다.
