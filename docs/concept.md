## 배경: 왜 만드는가

바이브 코딩으로 여러 프로젝트를 병렬 작업할 때의 혼란을 해결하기 위함.

### 사용자 페인 포인트

1. 병렬 작업이 많아 정신이 없다
2. "제작"과 "배포"를 나누고 싶다 (투두리스트는 제작만 가능, 배포는 반복적)
3. 프로젝트 단위로 보고 싶지만 매번 태그/레이블 세팅은 귀찮다
4. 오늘 반드시 끝내야 할 일 하나가 눈에 보였으면 좋겠다
5. 아침/저녁/밤 타임라인별로 우선순위 1,2,3을 세팅하고 싶다
6. 미루기, 반복, 백로그가 한눈에 보이면 좋겠다
7. 반복 루틴 스케줄 = 배포 (예: 쓰레드 배포, 링크드인 배포)

### 핵심 인사이트

> 이 문제는 "할 일 목록"이 아니라 **"오늘의 시간 배분"** 문제다.

---

## UX 원칙

> todoslot은 생산성 도구이기 전에 **게임**이다.

1. **"감"이 중요하다** -- 재밌어야 한다. 쾌감이 있어야 한다. 게임하듯이 깨는 느낌.
2. **드래그 앤 드랍이 기본** -- 슬롯에 끼워넣는 촉감. 클릭-선택보다 잡아서-놓기.
3. **전략적 재미** -- 9칸이 제한되어 있으니 "어디에 뭘 넣을까?" 전략이 생긴다.
4. **실패에도 선택지** -- 못했으면 미루기(백로그로) 또는 또하기(재배정). 막다른 골목 없음.
5. **3초 규칙** -- 지금 뭘 해야 하는지 3초 안에 파악 가능해야 한다.

## 컨셉: 목표 대시보드 (Goal Compass)

화면 최상단, 시간표보다 위에 위치하는 "방향 확인" 섹션.
할 일을 실행하기 전에 **왜 하는지**를 먼저 상기시킨다.

### 구조

```
┌─────────────────────────────────────────────┐
│  나는 [____________________________]        │  ← 자기 정의 인풋 (한 문장)
├─────────────────────────────────────────────┤
│                                             │
│  ◎ 10년 뒤   최고의 프로덕트 디자이너가 된다  │
│  ◎ 5년 뒤    자체 SaaS 3개 운영             │
│  ◎ 1년 뒤    todoslot MAU 1만 달성          │
│  ─────────────────────────────────────────  │
│  Q1 목표     MVP 출시 + 100명 온보딩         │
│  Q2 목표     유료 전환율 5% 달성             │
│  Q3 목표     팀 빌딩 (디자이너 1명)          │
│  Q4 목표     시리즈 시드 라운드              │
│  ─────────────────────────────────────────  │
│  🔥 오늘     todoslot 시간표 UI 완성         │  ← 강조 하이라이트
│  ─────────────────────────────────────────  │
│  💬 확언     "출시하지 않으면 아무것도 아니다" │  ← 사용자가 직접 작성
│                                             │
└─────────────────────────────────────────────┘
```

### "나는" 인풋

- 화면 최상단 고정, 한 문장으로 자기 정체성 정의
- 예: "나는 **만드는 사람**이다", "나는 **1인 창업자**다"
- 모든 목표의 기준점 — 이 문장에 부합하지 않는 일은 백로그에서도 제거 고려

### 목표 계층

| 레이어 | 역할 | 갱신 주기 |
|--------|------|-----------|
| 10년 뒤 | 북극성 (방향) | 드물게 |
| 5년 뒤 | 중기 비전 | 연 1회 |
| 1년 뒤 | 연간 목표 | 연 1~2회 |
| 분기 목표 (Q1~Q4) | 실행 단위 | 분기마다 |
| 오늘 당장 | 오늘의 핵심 1개 | 매일 |
| 확언 | 심리적 앵커 | 수시 교체 |

### 오늘 당장 끝내야 할 일

- 시간표의 "지금 할 것"과 연동 가능 (같은 항목 or 별도 지정)
- 목표 대시보드에서는 **하루 전체의 최우선 1개**
- 시간표의 "지금 할 것"은 **현재 시간대의 최우선 1개**
- 둘 다 눈에 띄게 강조하되 맥락이 다름

### 확언 (Affirmation)

- **사용자가 직접 입력한다** (프리셋/랜덤 로테이션 없음)
- 본인의 말로 쓴 것만 의미 있다
- 목표와 함께 보여서 동기부여 유지
- 예: "출시하지 않으면 아무것도 아니다", "매일 1% 더 나아지자"

### 현재 타임라인 하이라이트

- 시간표에서 **현재 시간대 행이 자동 하이라이트**
- 아침(06~12) → 아침 행 활성, 저녁/밤은 dimmed
- 시간이 바뀌면 실시간으로 하이라이트 전환
- "지금 내가 어디에 있는지" 즉각 인지
- 지나간 시간대는 완료/미완료 상태에 따라 시각 피드백 (체크 or 경고)

## 컨셉: 9칸 시간표 (Timetable Grid)

학교 시간표 메타포:
- 행 = 시간대 (아침 / 저녁 / 밤)
- 열 = 우선순위 (1순위 / 2순위 / 3순위)
- 각 셀에 할 일 하나
- 하루 최대 9개 → 강제 우선순위화

### 시간대 정의

| 시간대 | 기본 범위 | 성격 |
|---|---|---|
| 아침 | 06:00 ~ 12:00 | 집중 작업 (제작) |
| 저녁 | 12:00 ~ 18:00 | 혼합 (제작 + 배포) |
| 밤 | 18:00 ~ 24:00 | 가벼운 작업 (배포, 리뷰) |

> 시간 범위는 사용자 커스텀 가능

### 자동 분류: 태그 없이 제작 vs 배포

기존 투두앱의 문제: 카테고리, 태그, 레이블 → 매번 세팅 귀찮음

todoslot의 해법:
- **태스크** = 반복 없는 일회성 항목 → 자연스럽게 "제작" 성격
- **루틴** = 반복 스케줄이 있는 항목 → 자연스럽게 "배포" 성격
- 사용자가 명시적으로 분류할 필요 없음. **반복 여부가 곧 분류.**

### 프로젝트 = 색 점

복잡한 프로젝트 관리 대신:
- 프로젝트 생성 = **이름 + 색 하나** (그게 전부)
- 할 일 카드에 프로젝트 컬러 도트 자동 표시
- 사이드바에서 프로젝트별 필터링 가능

### "지금 할 것" (Now Focus)

- 화면 최상단에 현재 시간대의 1순위가 자동 표시
- 큰 폰트, 강조 배경
- "이것만 하면 된다" 심리적 앵커

### 미루기 메커니즘

- **미루기 = 백로그로 보냄**
- 슬롯이 비워지고, 항목은 백로그에서 대기
- 나중에 다시 드래그 앤 드랍으로 슬롯에 배정 가능
- 미룬 횟수 누적 표시 (e.g. 3)
- "3번 미뤘네, 진짜 할 건가?" 자각 유도

### 또하기 메커니즘

- **또하기 = 항목을 복사하여 새로운 슬롯에 재배정 가능하게 함**
- 원본은 그대로, 복사본이 백로그에 생성
- 드래그 앤 드랍으로 원하는 슬롯에 배치
- 용도: 못 끝낸 작업을 다른 시간대에 이어서 / 비슷한 작업을 반복 수행
- (임시 워딩 -- 더 나은 이름 추후 검토)

### 루틴 (반복 항목)

- 시각적 차별화: 점선 테두리 + ↻ 아이콘 + 회색 배경
- 주기: 매일 / 매주 / 격주 / 매월
- 완료 시 → 다음 발생일에 자동 재생성
- 시간표에서 루틴 비율이 보이면 → 시간 배분 자각

### 백로그

- 스케줄되지 않은 모든 항목
- 하단에 접힌 상태로 표시, 펼쳐서 확인
- 프로젝트별로 그룹핑
- 여기서 골라서 드래그 앤 드랍으로 시간표 슬롯에 배치
- **미루기된 항목도 이곳으로 돌아온다**

## 인터랙션 플로우

### 빠른 추가
```
상단 인풋 → 텍스트 입력 → 백로그에 추가
                        → 최근 사용 프로젝트 자동 연결
```

### 스케줄링 (드래그 앤 드랍)
```
백로그 항목을 잡아서 → 빈 슬롯에 드랍
또는
빈 슬롯 클릭 → 백로그에서 선택
```

### 완료
```
체크 → 취소선 + fade-out 애니메이션 → 완료 목록으로
슬롯을 깬 쾌감!
```

### 미루기
```
미루기 버튼 → 백로그로 이동 → 슬롯 비워짐 → 미룬 횟수 +1
```

### 또하기
```
또하기 버튼 → 항목 복사본 백로그에 생성 → 드래그 앤 드랍으로 재배정
```

## macOS 위젯 (Phase 3)

### Small 위젯 (작은 사이즈)
```
┌──────────────┐
│ 지금 할 것   │
│              │
│ 플로디 사이드 │
│ 바 리팩터링   │
│         ━━○  │  ← 진행 느낌
└──────────────┘
```

### Medium 위젯 (중간 사이즈)
```
┌──────────────────────────────┐
│ 지금: 플로디 사이드바 리팩터링 │
│                              │
│ 다음: 버그 수정  |  그 다음: PR│
│         저녁 1순위    저녁 2순위│
└──────────────────────────────┘
```

### 구현 방법
1. **WidgetKit** (Swift) — iOS/macOS 네이티브 위젯
2. 웹앱 API에서 "현재 슬롯" 데이터 제공
3. 위젯은 읽기 전용, 탭하면 웹앱으로 이동
