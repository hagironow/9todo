# todoslot 컨셉 문서

> 2026-05-04 기획 세션에서 도출

## 배경: 왜 만드는가

바이브 코딩으로 여러 프로젝트를 병렬 작업할 때의 혼란을 해결하기 위함.

### 사용자 페인 포인트

1. 병렬 작업이 많아 정신이 없다
2. "제작"과 "배포"를 나누고 싶다 (투두리스트는 제작만 가능, 배포는 반복적)
3. 프로젝트 단위로 보고 싶지만 매번 태그/레이블 세팅은 귀찮다
4. 오늘 반드시 끝내야 할 일 하나가 눈에 보였으면 좋겠다
5. 아침/저녁/밤 타임라인별로 우선순위 1,2,3을 세팅하고 싶다
6. 미루기, 반복, 백로그가 한눈에 보이면 좋겠다
7. 반복 루틴 스케줄 = 배포 (예: 쓰레드 배포, 링크드인 배포)

### 핵심 인사이트

> 이 문제는 "할 일 목록"이 아니라 **"오늘의 시간 배분"** 문제다.

## 컨셉: 9칸 시간표 (Timetable Grid)

학교 시간표 메타포:
- 행 = 시간대 (아침 / 저녁 / 밤)
- 열 = 우선순위 (1순위 / 2순위 / 3순위)
- 각 셀에 할 일 하나
- 하루 최대 9개 → 강제 우선순위화

### 시간대 정의

| 시간대 | 기본 범위 | 성격 |
|---|---|---|
| 아침 | 06:00 ~ 12:00 | 집중 작업 (제작) |
| 저녁 | 12:00 ~ 18:00 | 혼합 (제작 + 배포) |
| 밤 | 18:00 ~ 24:00 | 가벼운 작업 (배포, 리뷰) |

> 시간 범위는 사용자 커스텀 가능

### 자동 분류: 태그 없이 제작 vs 배포

기존 투두앱의 문제: 카테고리, 태그, 레이블 → 매번 세팅 귀찮음

todoslot의 해법:
- **태스크** = 반복 없는 일회성 항목 → 자연스럽게 "제작" 성격
- **루틴** = 반복 스케줄이 있는 항목 → 자연스럽게 "배포" 성격
- 사용자가 명시적으로 분류할 필요 없음. **반복 여부가 곧 분류.**

### 프로젝트 = 색 점

복잡한 프로젝트 관리 대신:
- 프로젝트 생성 = **이름 + 색 하나** (그게 전부)
- 할 일 카드에 프로젝트 컬러 도트 자동 표시
- 사이드바에서 프로젝트별 필터링 가능

### "지금 할 것" (Now Focus)

- 화면 최상단에 현재 시간대의 1순위가 자동 표시
- 큰 폰트, 강조 배경
- "이것만 하면 된다" 심리적 앵커

### 미루기 메커니즘

- 미루기 = 다음 시간대로 이동
- 밤 시간대에서 미루면 → 내일 아침으로
- 미룬 횟수 누적 표시 (e.g. ③)
- "3번 미뤘네, 진짜 할 건가?" 자각 유도

### 루틴 (반복 항목)

- 시각적 차별화: 점선 테두리 + ↻ 아이콘 + 회색 배경
- 주기: 매일 / 매주 / 격주 / 매월
- 완료 시 → 다음 발생일에 자동 재생성
- 시간표에서 루틴 비율이 보이면 → 시간 배분 자각

### 백로그

- 스케줄되지 않은 모든 항목
- 하단에 접힌 상태로 표시, 펼쳐서 확인
- 프로젝트별로 그룹핑
- 여기서 골라서 시간표 슬롯에 배치

## 인터랙션 플로우

### 빠른 추가
```
상단 인풋 → 텍스트 입력 → 백로그에 추가
                        → 최근 사용 프로젝트 자동 연결
```

### 스케줄링
```
백로그 항목 클릭 → 3x3 격자 팝업에서 시간대 + 순위 선택
또는
빈 슬롯 클릭 → 백로그에서 선택
```

### 완료
```
체크 → 취소선 + fade-out 애니메이션 → 완료 목록으로
```

### 미루기
```
미루기 버튼 → 다음 시간대로 자동 이동 → 미룬 횟수 +1
```

## macOS 위젯 (Phase 3)

### Small 위젯 (작은 사이즈)
```
┌──────────────┐
│ 지금 할 것   │
│              │
│ 플로디 사이드 │
│ 바 리팩터링   │
│         ━━○  │  ← 진행 느낌
└──────────────┘
```

### Medium 위젯 (중간 사이즈)
```
┌──────────────────────────────┐
│ 지금: 플로디 사이드바 리팩터링 │
│                              │
│ 다음: 버그 수정  |  그 다음: PR│
│         저녁 1순위    저녁 2순위│
└──────────────────────────────┘
```

### 구현 방법
1. **WidgetKit** (Swift) — iOS/macOS 네이티브 위젯
2. 웹앱 API에서 "현재 슬롯" 데이터 제공
3. 위젯은 읽기 전용, 탭하면 웹앱으로 이동

## 기술 스택

### Phase 1 (POC)
- Next.js (App Router) · React · TypeScript
- Tailwind CSS · shadcn/ui (flowdy에서 검증된 조합)
- 데이터: 로컬 JSON 파일 (flowdy 패턴 재활용)

### Phase 2+ (확장)

- 위젯: Swift WidgetKit
- 동기화: 추후 결정
