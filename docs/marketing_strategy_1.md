## S+ 티어: 프로덕트 헌트

**왜 1순위인가:** 타겟(메이커/1인 창업자)이 정확히 모여있는 곳. 성공하면 글로벌 도달.

준비 항목:
- PH 계정 만들고 다른 제품 5개 이상 업보트/코멘트
- Maker 프로필 세팅
- 티저 페이지(Coming Soon) 등록
- PH용 에셋 준비: 로고, 갤러리 이미지 5장, GIF/영상 1개, 태그라인
- 헌터(Hunter) 섭외
- 런칭 타이밍: 화~목 오전 (PST 00:01)

## S 티어: 레딧 + 인플루언서 리뷰

### 레딧
- 타겟: r/productivity, r/SideProject, r/indiehackers, r/ADHD
- 후킹: "I built a todo app that only lets you have 9 tasks per day. Here's why."
- 스토리텔링 접근 — 광고 아닌 경험 공유
- 이번주 최소 2개 포스트

### 인플루언서 리뷰 (무예산)
- 구독자 1만~10만 급 생산성 유튜버/쓰레드 계정
- "리뷰 요청" 아닌 "피드백 요청" 프레이밍
- 이번주 10명 DM 목표

## A 티어: 메타 광고 + 쓰레드 + 링크드인

### 메타 광고 (10만원/주)
- 타겟: 관심사 "생산성/투두/프리랜서/사이드프로젝트", 25-40세
- 크리에이티브 3종 A/B 테스트:
  1. "할 일 20개 적어놓고 2개만 끝내는 당신에게"
  2. "하루 9칸. 더 못 넣음. 그래서 잘 됨."
  3. "투두리스트 말고 시간표 짜세요"
- 일 예산 ~14,000원, 3일 후 하위 크리에이티브 끄고 상위 집중

### 쓰레드 매일 1개
- 월: 빌딩 일지 / 화: 생산성 인사이트 / 수: 기능 소개 / 목: 공감글 / 금: 주간 회고

### 링크드인
- 글 2개 (화/목), 개인 스토리 + 제품 자연 노출
- 1인 창업자/프리랜서 10명 DM

## B 티어: 인스타 + 브런치

### 인스타 반복 콘텐츠 시리즈
| 시리즈 | 포맷 | 반복성 |
|--------|------|--------|
| "오늘의 9칸" | 본인 9칸 스크린샷 + 한 줄 | 매일 |
| "Before/After" | 할 일 20개 → 9칸 정리 | 무한 |
| "9칸 챌린지" | 팔로워 참여 유도 | 주간 |
| 생산성 팁 카드뉴스 | "왜 투두는 실패하는가" | 무한 |

### 브런치
- 주 1회 장문 에세이
- 빌더 스토리 중심

## C 티어: 커뮤니티 + 단톡방
- 클리앙 자작마당 1개, 뽐뿌 1개 — "피드백 주세요" 프레이밍
- 단톡방은 1:1 추천만
