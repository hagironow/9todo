# 9block

9칸 시간표 기반 투두 앱. 하루를 3시간대 x 3순위 = 9슬롯으로 제한해서 강제로 우선순위를 정하게 만든다.

## 문제

바이브 코딩하면서 병렬 작업이 많아지면 정신이 없다.

- **제작**(코딩)과 **배포**(쓰레드, 링크드인 등)가 뒤섞임
- 프로젝트 단위로 보고 싶은데, 매번 태그/레이블 세팅은 귀찮음
- "오늘 반드시 끝낼 것 하나"가 눈에 안 보임
- 미룬 일이 얼마나 쌓였는지 감이 없음

## 핵심 컨셉

### 9칸 시간표 (Timetable Grid)

```
┌─────────────────────────────────────────────┐
│  지금 할 것: 플로디 사이드바 리팩터링         │  ← 현재 시간대 1순위 자동 승격
└─────────────────────────────────────────────┘

         1순위          2순위          3순위
┌──────────────┬──────────────┬──────────────┐
│ 아침         │              │              │
│ 플로디 사이드 │ 버그 수정     │ PR 리뷰      │
│ 바 리팩터링   │              │              │
├──────────────┼──────────────┼──────────────┤
│ 저녁         │              │              │
│ 쓰레드 배포 ↻│ 투두앱 POC   │ (빈 슬롯)    │
│              │              │              │
├──────────────┼──────────────┼──────────────┤
│ 밤           │              │              │
│ 링크드인 배포↻│ 코드 리뷰    │ (빈 슬롯)    │
│              │              │              │
└──────────────┴──────────────┴──────────────┘

        ─── 백로그 (접힘) ──────────────
        ▸ flowdy: 페이지 사전 개선, ...
        ▸ 투두앱: DB 설계, ...
        ▸ 루틴: 주간 회고 (매주 금) ↻
```

### 설계 원칙

1. **태그 없이 자동 분리** — 반복 여부가 곧 분류. 루틴(↻) = 배포, 태스크 = 제작
2. **9칸 제약 = 강제 우선순위화** — 슬롯이 꽉 차면 뭘 뺄지 고민하게 만듦
3. **프로젝트 = 색 점** — 이름 + 색 하나 선택. 그게 전부
4. **미루기 = 다음 시간대로 이동** — 밤이면 내일 아침. 미룬 횟수 표시
5. **루틴은 점선 + ↻** — 완료하면 다음 발생일에 자동 재생성

### 인터랙션

| 동작 | 설명 |
|---|---|
| 빠른 추가 | 상단 인풋 → 백로그에 추가 |
| 스케줄링 | 백로그 항목 클릭 → 시간대 + 순위 선택 (3x3 격자 팝업) |
| 완료 | 체크 → 취소선 + fade-out |
| 미루기 | 다음 시간대로 이동, 미룬 횟수 누적 표시 |
| 루틴 생성 | 새 항목 + "반복" 토글 → 주기 선택 |

### 레이아웃

- **데스크톱**: 3x3 격자 전체 + 좌측 프로젝트 사이드바 + 하단 백로그
- **모바일**: 탭으로 시간대 전환 (아침|저녁|밤) + 세로 리스트
